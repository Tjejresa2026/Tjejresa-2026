# Tjejresan 2026 – skarp PWA-prototyp

Detta är en mobilvänlig PWA-version med grön/blå Medelhavsdesign.

## Installera
Publicera mappen via HTTPS (t.ex. GitHub Pages/Netlify/Vercel) och öppna adressen i mobilen. Välj "Lägg till på hemskärmen" / "Installera app".

## Arrangör
Lösenord i denna prototyp: Malta2026!

## Obs
För riktig fleranvändarsynk behöver nästa version kopplas till en server/databas. Då kan du och Marie ändra schema, länkar och överraskningar från en arrangörsvy och alla gästers mobiler uppdateras direkt.
